# QuickG76

Kalkulator G-Code G76 untuk CNC Threading.

## Fitur

- Kalkulasi G-code G76 (absolut & integer mode)
- Katalog ulir: Metrik, UNC, UNF, NPT, BSPT, BSPP, Trapesium, Segiempat, BSW, BSF
- Input manual dengan dukungan ulir tirus (taper)
- Estimasi waktu siklus berdasarkan RPM spindle
- Diagram penampang ulir real-time
- Export G-code (.NC, .CNC, .TXT, .PDF)
- Dark/Light mode

## Build & Jalankan

```bash
npm install
npm run build    # export web + PWA
npm run serve    # serve di http://localhost:8080
```
